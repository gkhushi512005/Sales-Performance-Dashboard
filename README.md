# Sales Performance Dashboard

## Overview

The **Sales Performance Dashboard** is a data analytics project designed to monitor and analyze sales performance across different regions, products, and time periods. The dashboard helps businesses track key performance indicators (KPIs), identify sales trends, evaluate top-performing products, and make data-driven decisions to improve revenue and profitability.

The dashboard provides insights into:

* Total Sales Revenue
* Profit Analysis
* Sales Trends Over Time
* Region-wise Performance
* Product Category Performance
* Top and Bottom Performing Products
* Customer and Market Analysis

---

## Tools Used

* Microsoft Excel – Data Cleaning and Preparation
* Microsoft Power BI – Dashboard Development and Visualization
* Power Query – Data Transformation and Cleaning
* DAX – Creating Calculated Measures and KPIs

---

## Dataset

The dataset contains sales transaction records with the following information:

| Column Name   | Description                      |
| ------------- | -------------------------------- |
| Order ID      | Unique identifier for each order |
| Order Date    | Date of purchase                 |
| Customer Name | Name of customer                 |
| Product Name  | Product sold                     |
| Category      | Product category                 |
| Region        | Sales region                     |
| Quantity      | Number of units sold             |
| Sales         | Revenue generated                |
| Profit        | Profit earned from sales         |
| Discount      | Discount offered                 |

### Dataset Features

* Historical sales records
* Multiple product categories
* Regional sales data
* Revenue and profit metrics
* Customer purchasing information

---

## Key Dashboard Insights

* Track overall sales and profit performance.
* Identify high-performing regions and products.
* Monitor monthly and yearly sales trends.
* Compare sales across categories.
* Analyze customer purchasing behavior.
* Support business decision-making through interactive visualizations.

---

## Conclusion

This Sales Performance Dashboard transforms raw sales data into meaningful business insights. By leveraging interactive visualizations and KPI tracking, organizations can better understand their sales performance, identify growth opportunities, and make informed strategic decisions.
