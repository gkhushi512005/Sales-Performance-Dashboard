Sales Performance Dashboard
Overview

This project is an interactive dashboard built to analyze and visualize sales performance. It helps businesses track revenue, orders, product performance, regional sales, and customer trends through easy-to-understand visualizations.

Features
Total Revenue KPI
Total Orders KPI
Quantity Sold Analysis
Average Order Value (AOV)
Sales Trend Analysis
Regional Performance Analysis
Product Category Analysis
Interactive Filters and Slicers
Dynamic Charts and Reports
Tools Used
Power BI
DAX (Data Analysis Expressions)
Excel/CSV Dataset
Data Modeling
Data Visualization Techniques
Dashboard Insights
Revenue trends over time
Best-performing products
Top-performing regions
Customer purchasing patterns
Sales growth comparison across periods
Files Included
Sales_Dashboard.pbix – Power BI Dashboard File
sales_data.csv – Sales Dataset
date_table.csv – Date Dimension Table
README.md – Project Documentation
Business Benefits
Tracks sales performance in real time
Identifies high-performing products and regions
Supports data-driven decision making
Helps improve revenue and profitability
